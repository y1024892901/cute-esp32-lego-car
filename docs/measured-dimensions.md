# 真实硬件三维尺寸与包络数据库（Dimension & Envelope Database）

> **管理原则**：
> 1. 所有尺寸单位统一为 **毫米（mm）**。
> 2. **PCB 裸板尺寸 $\neq$ 模块安装包络尺寸**。布局与碰撞检测一律采用包含散热片、排针、插头、线材弯折半径与螺丝刀操作空间的 **最大包络尺寸（Envelope）**。
> 3. 每个尺寸均明确标注来源等级：
>    - `VERIFIED_DATASHEET`：标准工业/开源模块官方机械图纸确认
>    - `SELLER_SPEC`：淘宝订单商品标题或详情页标准规格
>    - `ESTIMATED`：工程保守包络裕量估算
>    - `MEASURE_REQUIRED`：**存在批次/副厂差异，必须使用游标卡尺实测核对后方可锁定最终生产图纸**

## 二、乐高积木标准几何基准参数（`VERIFIED_DATASHEET`）

为保证亚克力底盘、3D 打印/定制转接件与标准乐高积木（LEGO System / Technic 及高砖 Gobricks 兼容件）100% 物理咬合，全项目严格执行以下乐高官方几何公差基准：

| 乐高几何参数 | 符号 | 标准理论值 (mm) | 工程制造配合值 (mm) | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| **单凸粒水平模数（1 Stud / 1L）** | `P_stud` | `8.00` | `8.00` | 所有乐高孔位、柱位、长宽跨度必须为 `8.00mm` 的整数倍 |
| **标准砖块外廓负公差** | `delta_brick` | `-0.20`（单边 `-0.10`） | `-0.20` | $N$ 单位砖实际外宽为 $8N - 0.2\text{ mm}$（例如 $16\text{ Studs} = 127.8\text{ mm}$） |
| **标准板高（1 Plate）** | `H_plate` | `3.20` | `3.20` | 3 层板高 = 1 标准砖高（$3 \times 3.2 = 9.6\text{ mm}$） |
| **标准砖高（1 Brick）** | `H_brick` | `9.60` | `9.60` | 不含顶部凸粒高度 |
| **顶部凸粒（Stud）直径 × 高度** | `D_stud × H_stud` | `Ø4.80 × 1.80` | `Ø4.80 × 1.80` | 凸粒中心间距严格为 `8.00mm` |
| **科技砖（Technic Brick）销孔直径** | `D_pinhole` | `Ø4.85`（带沉孔 `Ø6.1`） | `Ø4.85` | 可直接穿入标准乐高摩擦销（`2780`）或 **M4 螺丝 / 带衬套 M3 螺丝** |
| **科技砖销孔中心距底面高度** | `H_technic_center` | `5.80` | `5.80` | `1×N` 科技孔砖（如 `3702`/`3894`）底面至圆孔中心距离为 `5.80mm` |
