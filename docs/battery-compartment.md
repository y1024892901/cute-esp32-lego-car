# 核心电池仓结构与电气安全设计（Battery Compartment Design）

> **强制设计准则**：电池仓不是车壳完成后的“塞入式附件”，而是决定底盘轴荷分配、质心高度和供电安全的**一号核心结构件**。

---

## 一、现有电池与充电器件的问题诊断（基于 `订单数据.xlsx`）

1. **Row 37（`18650平头9800买2节送双充【2600毫安】`）**：
   - 实际为 **2 节 18650 平头（Flat-Top）锂离子裸电芯**（标称电压 `3.7V`，满电 `4.2V`，截止 `3.0V`，单节重约 `46g`）。
   - **平头电芯的两大隐患**：
     1. **正极接触不良**：平头 18650 的正极帽与外皮齐平甚至微凹，而 Row 36 购买的 `￥0.53` 廉价塑料串联电池盒正极多为平面弹片且两侧有防反接塑料凸筋，平头电芯装入后极易因塑料筋阻挡而无法接触正极弹片，或在车辆颠簸时瞬间断电重启！
     2. **无内置锂电保护板（Unprotected）**：平头电芯内部不含过充、过放和短路保护 IC。若在车上持续放电至单节 `<2.5V`，会导致电芯永久损坏甚至鼓包；若发生外部接线短路，瞬时短路电流可达 `15A~25A`，会直接烧毁 Row 36 电池盒自带的 26AWG 细引线。
2. **Row 14（`TP4056 1A Type-C 充放电保护一体板` ×2）**：
   - **严禁用于本车 2S（7.4V/8.4V）串联电池组**！TP4056 为单节（1S 4.2V）线性充电管理芯片，其输入负端（`IN-`）与电池负端（`BAT-`）内部直通。若用两块 TP4056 同时接在两节串联电池上并共用一个 5V USB 电源供电，会直接将第一节电池正负极通过 USB 地线硬短路！
3. **Row 11（`2串锂电池升压快充模块_紫板` ×1）**：
   - 该模块可将 5V Type-C 输入升压至 `8.4V` 为 2 串锂电池充电，但**模块本身不含双节电压均衡与过放保护功能**。

## 二、电池仓空间布置与机械固定设计

### 1. 黄金重心位置：下层底盘几何正中（Low-Center Belly Bay）
- **三维坐标范围**：
  - 纵向：$X \in [-38.0,\ +38.0]\text{ mm}$（完美处于前轴 $X=+45\text{ mm}$ 与后轴 $X=-45\text{ mm}$ 正中间，前后轴荷比接近 $50:50$）
  - 横向：$Y \in [-20.5,\ +20.5]\text{ mm}$（严格对称于车身纵轴线 $Y=0$）
  - 垂向：$Z \in [12.0,\ 33.0]\text{ mm}$（直接坐落在 $Z=9\sim 12\text{ mm}$ 的 3mm 下层亚克力主底盘上，质心高度仅 $Z_{\text{bat}} = 22.5\text{ mm}$）
- **安全隔离间距**：
  - 距左右两侧 `1812-N20` 蜗轮箱内壁净距：**`9.5 mm`**（即使 `1812-N20` 双出长轴向内伸出 `8.0 mm`，仍保留 `1.5 mm` 旋转安全间隙，且电池盒两侧设有 `3mm` 亚克力防撞限位条，**绝对不会让转动轴接触电池或电池盒**）。
  - 距上层电子板底面（$Z = 47.0\text{ mm}$）净距：**`14.0 mm`**（杜绝上层焊点刺破电池）。
  - 距两块高温 `L298N` 散热片（位于上层 $Z = 50 \sim 77\text{ mm}$）垂直距离 `> 20 mm` 且隔着 3mm 亚克力层，完全热隔离。

### 2. 抗振动固定与平头电芯防断电改造
1. **底座刚性锁固 + 亚克力四面限位框**：
   - 电池盒底部通过 **2 颗 `M3 × 8mm` 沉头螺丝 + 螺母** 锁紧在下层底盘中心孔位（底面沉孔或加垫防刮绝缘垫片）。
   - 利用亚克力边角料（或 3D 打印限位框）在电池盒四周粘接 `4mm` 高的 U 型限位挡边，消除电池盒水平滑移。
2. **20mm 宽魔术贴绑带环抱**：
   - 下层底盘在 $Y = \pm 23.0\text{ mm}$ 处各开两条 `22.0 × 3.5 mm` 穿带槽，用一条魔术贴扎带将两节 18650 电芯牢牢压在电池盒槽内，彻底防止颠簸跳脱。
3. **平头电芯接触增强措施（二选一，强烈推荐 B）**：
   - **方案 A（零成本改装现有盒）**：用美工刀削平 Row 36 电池盒正极弹片两侧凸起的塑料挡筋，并在正极弹片上点焊一个高 `1.5mm` 的圆润焊锡凸点（利用已购的德力西电烙铁 Row 40 与焊锡丝 Row 09），同时将原盒 26AWG 细线改焊为您已买的 **`20AWG 特软硅胶线`（Row 34/35）**。
   - **方案 B（￥4.5 升级高可靠电池盒）**：采购 1 个 **带加粗镀镍弹簧/铜柱触点的 18650 两节串联平头通用电池盒（带盖或强力弹簧款）** + **2 颗 `Ø6×1.5mm` 钕铁硼强磁铁吸片**（直接吸在平头电池正极秒变尖头电池）。

## 三、电池充放电保护、开关与熔断器安全回路

```
[18650 电芯 #1 (3.7V)] ──串联── [18650 电芯 #2 (3.7V)]
        │ (0V)                │ (3.7V BM中点)           │ (+7.4V~8.4V)
        └─────────┬───────────┴───────────┬─────────────┘
                  ▼                       ▼
        ┌───────────────────────────────────────────┐
        │   2S 8A 锂电池均衡保护板 (2S BMS 模块)    │  <── 过充(4.25V)/过放(2.75V)/过流(8A)/短路保护
        └─────────┬───────────────────────┬─────────┘
             P- (GND)                P+ (+7.4V~8.4V)
                  │                       │
                  │               [5A 玻纤管/插片保险丝] (短路熔断保护)
                  │                       │
                  ├───────────────┐       ├───────────────┐
                  ▼               ▼       ▼               ▼
         [2串升压快充紫板]        [XT60PB-F/M 板式对插头 (Row 28/29)]
         (车尾 Type-C 充电口)              │
                                  [KCD11 6A 船型电源总开关] (车尾右侧面板)
                                          │
                          ┌───────────────┴───────────────┐
                          ▼                               ▼
             [2× L298N 的 12V/VMS 动力端]     [LM2596S 降压模块 IN+ (调至 5.00V)]
             (直驱 4 台 6V N20 电机)           (专供 ESP32 + SU-03T + HC-SR04)
```

### 电池拆装与双模式充电维护流程
1. **日常免拆车充电（推荐）**：关闭车尾右侧 **KCD11 主电源总开关**，直接将手机 5V Type-C 充电线插入车尾 **2串升压快充紫板（Row 11）** 接口，经 2S BMS 均衡保护板安全充满至 `8.4V` 自动停充。
2. **拆电芯外部座充（备用）**：向上轻轻拔开可拆卸乐高车顶盖，拧松上层板前部 2 颗手拧滚花螺母并后翻上层电子板，解开魔术贴绑带即可垂直取出两节 18650 电芯，放入订单 Row 37 附赠的 **双槽独立座充** 充电。
3. **整盒独立快拆**：拔开电池仓尾部的 **`XT60PB` 公母插头（Row 28/29）**，即可将整个电池盒总成与车体电路完全物理断开。
